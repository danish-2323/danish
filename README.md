# Danish M — Personal Website

**Author:** Danish M

A personal website implemented with HTML, CSS and JavaScript. The repository contains the website source and static assets used to publish a personal web presence.

## Technology stack
- HTML5
- CSS3
- JavaScript

## Run locally

Clone the repository:

~~~bash
git clone https://github.com/danish-2323/danish.git
cd danish
~~~

Open index.html in a modern web browser or serve the directory using a local static web server.

## Deployment

The repository includes a sitemap and a static HTML entry point. It can be hosted using a static website hosting service. Configure the hosting provider's custom-domain and HTTPS settings as required.
